Prima pagina Web con immagini di sfondo

Tecnologie: HTML5, CSS3, Git.

Una pagina web che presenta una immagina di sfondo, gli autori dell'immagine, link ad altre pagine web collegate con diversi sfondi di paesaggi. Esercizio su tag semantici, link esterni con target="_blank", immagini con alt significativo. Prima esperienza con le icone di Font Awesome.

Cosa ho imparato: scegliere il tag giusto in base al significato del contenuto e non all'aspetto visivo. Differenza tra <section> e <article>. Uso di <figure> e <figcaption> per le immagini con didascalia. Organizzare l'informazione in poco spazio mantenendo gerarchia visiva. Uso degli id per anchor interne. Pattern header / main / footer su una singola card.

Youtube Clone

Tecnologie: HTML5, CSS3, Font Awesome, Ion Icons.

Un clone della pagina principale di YouTube, con loghi, icone, thumbnails di preview, barra di ricerca. Esercizio su tag semantici, link esterni con target="_blank", immagini con alt significativo. Prima esperienza con le icone di Font Awesome.

Cosa ho imparato: utilizzare Flexbox per allineare e centrare correttamente immagini e contenuti. Utilizzo di Ion Icons e Font Awesome, per reperimento loghi e simboli da inserire nelle pagine Web.

Portfolio Personale

Tecnologie: HTML5, CSS3, Google Fonts, Font Awesome, Git, GitHub Pages.

La pagina che state vedendo. Costruita da zero in cinque giorni, partendo dal markup HTML e arrivando alla stilizzazione CSS completa con box model, pseudo-classi, pseudo-elementi e tipografia ragionata. Pubblicata online su GitHub Pages al termine della prima settimana di corso.

Cosa ho imparato: progettare una pagina pensando alla gerarchia dei contenuti prima del design. Stilizzare in modo consapevole partendo da un reset CSS. Gestire un repository Git con commit descrittivi. Pubblicare un sito statico online.
